Security Architecture

How Kastrava Protects You

No Tracking Headers

Kastrava never sends tracking headers, fingerprinting signals, or unique identifiers. Your browsing sessions are invisible.

  • No client ID headers
  • No telemetry beacons
  • No crash reporting with device info
  • No referrer leakage

Encrypted Local Storage

All your data — bookmarks, history, sessions — is stored locally in an encrypted SQLite database. No cloud sync means no cloud breach.

  • AES-256 encrypted database
  • No network-accessible storage
  • No shared browser profiles
  • Full user control over data

No External Requests

When you're browsing a page, Kastrava itself makes zero background requests. No update checks. No DNS prefetching. No safe browsing API calls with your IP.

  • No update pings
  • No DNS prefetching
  • No telemetry endpoints
  • No hidden background tasks

Download Protection

All downloads are handled through AnterGet, our built-in download manager. Files go directly to your machine. No cloud intermediary.

  • Direct file transfers
  • No download tracking
  • Built-in integrity checks
  • Pause & resume support

About

What is Kastrava?

Kastrava is the most private desktop browser ever built. Not "privacy-focused." Not "privacy-friendly." The most private. Full stop.

Most browsers are built around advertising. They track you, profile you, and sell your attention. Kastrava was built around the radical idea that a browser should just be a browser — a tool you control, not a platform that controls you.

Every feature in Kastrava was designed with one question: does this serve the user, or does this serve us? If it doesn't serve the user, it doesn't ship.

Design Principles

  • Privacy by Default — Zero telemetry. Zero data collection. Zero external requests. Not opt-in. Default.
  • Local-First Architecture — SQLite storage. No cloud, no sync, no accounts. Your data never leaves your device.
  • Minimal Footprint — 128 MB AppImage. ~120 MB RAM at idle. No background services eating your resources.
  • User Sovereignty — Every setting is yours. Every shortcut is configurable. No dark patterns, no hidden options.
  • Open Source — Built in the open. Inspect the code. Verify the claims. Trust nothing you can't verify.

What Makes It Different

Chrome tracks you. Firefox phones home. Safari sends telemetry to Apple. Edge is Microsoft's advertising vector. Opera is owned by a Chinese consortium. Every major browser has a conflict of interest.

Kastrava has no advertisers to please. No shareholders demanding engagement metrics. No product team optimizing for data harvesting. Just a browser that works for you, and only you.

Version 27 "Starship Explorer" brings Picture-in-Picture, Reader mode, Split view, the unique Tracking Radar, one-click screenshots, bookmark import/export, and a full keyboard shortcut suite — all without compromising a single byte of your privacy.

Architecture

Built Different. Literally.

Electron Core

Built on Chromium with full process isolation. Sandboxed rendering, GPU acceleration, and modern web standards.

SQLite Database

All persistent data in a single local SQLite file. No JSON dumps, no IndexedDB, no cloud-backed storage.

AnterGet Engine

Curl-based download manager with pause, resume, progress tracking, and speed display. No third-party services.

Session Manager

Full session persistence. Close and reopen exactly where you left off. No account sync needed.

Per-Tab Isolation

Each tab is an isolated webview. Separate process, separate session, separate memory space.

Zero Network Calls

The browser itself never phones home. No update checks, no telemetry, no DNS prefetching in the background.
